# README

## 現在の取り組み

自作フライトコンピュータの開発を進めています。
ESP32でPID制御・ステートマシン・LoRaテレメトリを実装し、ロケットへの搭載を想定したシステムを構築しました。

---

## これまでの取り組み

WebアプリとiOSアプリの開発を通じて、設計から運用までの一連の流れを習得しました。
「なぜその構成を選ぶのか」「どのように利用されるのか」を重視し、長期的に価値を生み出す仕組みの構築を目指してきました。

## 開発実績

**TSS Rocket Project**（2025〜）
自作フライトコンピュータの開発プロジェクト。センサー統合・状態管理・テレメトリ通信の基盤を構築。

**QuickRemind**
App Storeにリリースしたリマインダーアプリ。Swift / SwiftUIで開発。

**StripeGym**
Stripeの決済機能を体系的に習得するための実験アプリ。サブスクリプション・単発決済を実装。

**StockManager**
銘柄ごとに財務指標を取得・可視化する株管理ツール。yfinance × ChatGPTを組み合わせて実装。

## 設計方針

- 要件定義を重視。目的・ユーザー価値・リスク要因を明確化してから設計する
- 実装順序を体系化。DB → API → 認証 → UI → 非同期処理 → 外部連携 → 運用
- 運用を前提に設計。ヘルスチェック・監視・バックアップを明文化
