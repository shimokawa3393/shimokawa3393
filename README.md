# README

## はじめに
開発にあたっては「なぜその構成を選ぶのか」「どのように利用されるのか」を重視しています。  
**設計 → 実装 → 自動化 → 運用** の一連の流れを通じて、長期的に価値を生み出す仕組みを構築することを目指しています。

## 開発実績

### QuickRemind
App Storeにリリースしたリマインダーアプリ。  
- スケッチからUIを設計し、1行入力で直感的に通知登録  
- カテゴリー管理・Apple純正カレンダーとの連携など、日常利用に適した機能を実装  
- Swift / SwiftUI により開発、公開後も継続的に改善  

### StripeGym
Stripeの決済機能を体系的に習得するための実験アプリ。  
- サブスクリプション・単発決済の双方を実装  
- Webhook処理、認証、環境分離など本番水準の仕組みを再現  
- カリキュラム形式で学習し、実践的な決済基盤の知識を獲得  

### StockManager
銘柄ごとに財務指標を取得・可視化する株管理ツール。  
- yfinance × ChatGPT を組み合わせ、直感的な株式選定を支援  
- Django × React 構成で、認証・保存・再計算を一貫して実装  

### ストーリー生成Bot
SNS向けに物語を自動生成・投稿するBot。  
- ChatGPTを用いたストーリー生成  
- 自動投稿により、継続的にコンテンツを提供

## 設計方針

- **要件定義を重視**  
  - 目的、ユーザー価値、リスク要因を明確化し、計画的に設計  

- **実装順序を体系化**  
  - DB → API → 認証 → UI → 非同期処理 → 外部連携 → 運用  
  - 効率的かつ安定性の高い開発フローを確立  

- **運用を前提に設計**  
  - /healthz, /readyz によるヘルスチェック  
  - Sentry × Slack 通知  
  - バックアップ・復旧手順を明文化
