## 開発実績

**StockManager**  
銘柄ベースで財務指標を取得・計算・可視化する株管理ツール。  
yfinanceやChatGPTを連携し、直感的な株選定を目指す。

**ストーリー生成Bot**  
絵本を自動生成し、SNSに自動投稿するBot。  
共感や癒しを届ける仕組みとして実験中。
